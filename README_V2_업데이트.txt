수냉이네 Vercel + Supabase V2

V1 실사용 테스트에서 나온 문제를 한 번에 수정한 버전입니다.

반영:
- 재무정보 잠금: 오늘 예상매출 포함 실제로 가림
- 새로고침 0 깜빡임 → 로딩 중 '—'
- 수기확정: 예약인원 직접입력 + 다시 수정 가능
- 날짜 ◀ / 오늘 / ▶ 실제 이동
- 거래처명 클릭 시 예약페이지 새 탭
- 거래처 수정: prompt 연속창 제거, 한 화면 모달에서 저장
- 거래처 ☰ 드래그 정렬 + DB sort_order 저장
- 지출 추가/수정/삭제
- 입금 추가/수정/삭제 + FIFO 미수 자동상계 재계산
- 매출/입금 기간조회
- 손익분석 실제 DB 계산 연결
- 운영기록 실제 주문/입금/지출 조회
- 거래처 추가/거래중지
- V7 UI 유지

중요: 기존 Supabase를 이미 사용 중이라면 supabase_schema.sql 전체를 다시 실행하지 마세요.
대신 Supabase SQL Editor에서 아래 두 줄만 한 번 실행하세요:

alter table clients add column if not exists reservation_url text default '';
create table if not exists order_history (
 id bigint generated by default as identity primary key,
 order_date date not null, client_id text, action text not null, payload jsonb, created_at timestamptz default now()
);

배포:
Vercel에 V2 폴더를 새 버전으로 배포하면 됩니다.
기존 SUPABASE_URL / SUPABASE_SERVICE_ROLE_KEY 환경변수는 그대로 사용합니다.
